# 短链 + 访问数据 + 优惠券 — 上线清单

三个功能共用一个 Cloudflare Worker（`vivabien-api`）+ D1 数据库（`vivabien-data`）。
静态站不用动构建方式；后台 `admin.py` 通过共享密钥调 Worker。

> ⚠️ 顺序很重要：**先部署 Worker，再发布网站**。否则新页面里的埋点/优惠券接口会报错。

## 一、部署 Worker + D1（在电脑终端做一次）

```bash
cd ~/vivabien-web/worker

# 1) 建数据库，记下输出里的 database_id
npx wrangler d1 create vivabien-data
#    打开 worker/wrangler.jsonc，把 "database_id":"REEMPLAZAR_CON_ID" 换成上面的 id

# 2) 建表
npx wrangler d1 execute vivabien-data --remote --file=schema.sql

# 3) 设后台密钥（自己想一串强口令，等下第二步还要用同一串）
npx wrangler secret put ADMIN_KEY
#    粘贴你的口令，回车

# 4) 部署
npx wrangler deploy
```

部署后确认 Worker 路由已生效：`vivabien.xyz/s/*` 和 `vivabien.xyz/api/*` 走 Worker
（wrangler.jsonc 里的 routes 会自动创建；若报 zone 找不到，去 Cloudflare 后台
Workers & Pages → vivabien-api → Settings → Triggers 手动加这两条路由）。

## 二、把同一串密钥告诉后台

在 `~/vivabien-web/` 下建文件 `worker_admin_key.txt`，内容就是第 3 步那串口令：

```bash
cd ~/vivabien-web
echo '你刚才设的那串口令' > worker_admin_key.txt
```

（该文件已加进 .gitignore，不会上传。）然后**重启 admin.py**。

## 三、发布网站

后台点「🚀 发布上线」（或 `git push`）。发布后：
- 每个商品页会自动上报浏览、加购、结算到 D1
- 购物车页出现「优惠码」输入框

## 四、验证

1. 后台顶栏 →「🎟️ 优惠券」→ 选百分比、填 10 → 生成券码，列表出现该券。
2. 后台 →「🔗 短链」→ 选个商品 → 生成短链，复制。
3. 手机/无痕窗口打开那条短链 → 跳到商品页 → 加购 → 去购物车 → 输券码看到打折。
4. 后台 →「📊 数据」→ 近30天数字有变化；用刚才的短码查「访客足迹」看到点击/浏览/加购。

## 常见问题
- 三页顶部显示「部署 Worker 后即可用」：说明后台还没连上 Worker——检查 `worker_admin_key.txt`
  是否和 Worker 的 ADMIN_KEY 完全一致、Worker 是否部署成功。
- 券的「已用次数」不自动加：成交在 WhatsApp/COD 站外，Worker 收不到真实付款信号，
  核销以人工为准（这是设计取舍，已记录在案）。
